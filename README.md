## 概要 / About

NGTOをワールド上に設置したり、ワイヤーモデルを簡単に設置するための便利なツールです。<br>
自動車モデルとして収録されています。地面に設置して右クリックで使用します。<br>
<br>
This is a convenient tool for placing NGTO objects and wire models in the world more easily.<br>
It is included as a vehicle model. Place it on the ground and right-click it to use it.

## 注意事項 / Notice

NGTO Builder 2を使用する前に、**必ずワールドデータのバックアップを取ってください**。デバッグ中にワールドデータが破損した事例があります。<br>
このパックの使用によって生じた損害や損失について、作者は一切責任を負いません。<br>
<br>
Before using NGTO Builder 2, **make sure to back up your world data**. There have been cases where world data was damaged during debugging.<br>
The author is not responsible for any damage or loss caused by using this pack.

## ツール内容 / Tools

### ● 地面設置

線路/座標を指定して広い地面を生成します<br>
Generates a wide ground surface by specifying routes or coordinates.

### ● ライン設置

線路/座標を指定してワールド上に手持ちのミニチュアブロックを生成します<br>
Generates the miniature block you are holding in the world by specifying routes or coordinates.

### ● 計測

距離を測定する便利ツールです<br>
Provides a convenient tool for measuring distances.

### ● プロップ設置

角度をつけてワールド上に手持ちのミニチュアブロックを生成します<br>
Generates the miniature block you are holding in the world with an angle applied.

### ● プロップ配列設置

インベントリ内にあるミニチュアブロックの配置通りにワールド上に生成します<br>
Generates miniature blocks in the world according to their arrangement in your inventory.

### ● ワイヤー設置

手持ちのワイヤーアイテムとスロットバーにある碍子からワイヤーを設置します<br>
Places wires using the wire item you are holding and the insulators in your hotbar.

### ● ビーム設置

手持ちのワイヤーアイテムとスロットバーにある碍子から架線ビームを設置します<br>
Places overhead wire beams using the wire item you are holding and the insulators in your hotbar.

### ● 架線設置

手持ちのワイヤーアイテムとスロットバーにある碍子から架線を設置します<br>
Places overhead wires using the wire item you are holding and the insulators in your hotbar.
